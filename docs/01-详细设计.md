## 1. 产品定位

**lifeOS** 是一个面向个人的「人生管理系统」，把生活关键维度的数据收拢到一个仪表盘里：

| 板块 | 一句话定位 | 核心价值 |
|------|-----------|---------|
| 自律与生长 | 习惯打卡 + 四级计划 + **纸质阅读书架** | 让目标落地成每一天的动作，持续滋养心智 |
| 记账 | 登记每一笔收支与账户 | 知道钱花哪了、还剩多少 |
| 资产 | 实物设备 + VIP/订阅账号登记 | 到期不慌、资产有数 |
| 日常 | 朋友圈式的随手记录 | 留住生活的瞬间 |
| 主面板 | 总览一切 | 每天打开一眼看清「今天要做什么、读了多少、花了多少、什么快到期」 |

### 1.1 设计原则
1. **一个主面板总览一切**——不用在各板块间来回找信息。
2. **低摩擦录入**——打卡一键完成，记一笔 30 秒内，翻书记录随手敲页码，随手记录不打断思路。
3. **真实感与拟物美感**——纸质书无需强制传图，自动生成质感精装书封；深浅色系原生通透。
4. **云端存储、多端同步、可备份**——数据存于自己的服务器，手机/电脑多端实时同步，并支持一键导出/导入备份。
5. **一套核心、三端一致**——Windows 桌面 / 网页 / Android 手机共用同一套界面与数据，体验一致、维护成本最低。
6. **各端发挥所长**——手机上单手完成 90% 的随手操作（拍照、打卡、记一笔、翻书记录），桌面端做强表格与报表，网页端零门槛。

### 1.2 目标用户与场景
- **个人自用**，通过账号登录（邮箱 + 密码），Windows 桌面 / 网页 / Android 手机三端实时同步（手机上记账打卡翻书、电脑上看报表与复盘）。
- 典型一天：早上看主面板今日计划与在读书籍 → 白天随手打卡/记账/翻书页码记录 → 晚上写一条日常或书摘 → 月底看报表与阅读目标复盘。

### 1.3 多端体验差异

| | 网页端 | Windows 桌面端 | Android 手机端 |
|--|--------|---------------|---------------|
| 安装 | 免安装 / PWA 可安装 | 安装包（MSI/NSIS） | APK |
| 定位 | 零门槛访问 | 常驻后台、托盘提醒、开机自启 | 随身记录、拍照、随时打卡翻书 |
| 特色能力 | 任意设备浏览器打开 | 托盘 + 全局快捷键快捷记账 | 拍照记日常、系统分享入口 |

## 2. 板块详设

### 2.1 自我生长板块（自律与阅读） 🎯

#### 2.1.1 习惯打卡
- **习惯管理**：新增/编辑/归档习惯，字段见下表。
- **打卡交互**：今日列表里点一下即完成，再点取消；每天 N 次的习惯逐次累加次数；显示连续（streak）🔥。
- **目标频率语义（v2.2 修订，频率必须参与调度与统计）**：
  - **每天（daily）**：每天需完成 `timesPerPeriod` 次（默认 1 次，可设 N 次）。
  - **每周 N 次（weekly）**：弹性目标——自然周内任意完成 N 天即达标（每天最多计 1 次，再点取消当天），不限定星期几；今日列表常驻并标注「本周还需 N 次」。
  - **指定星期几（custom）**：`weekdays` 指定周一至周日（1–7），仅调度日需要打卡，非调度日不进入今日打卡列表与主面板统计分母。
- **连续（streak）按频率计算，避免惩罚式断签**：
  - daily：按自然日连续。
  - weekly：按「达标周」连续——一周内完成 ≥ N 次即达标，中断周才清零；展示为「连续 N 周」。
  - custom：仅统计调度日，非调度日跳过且不断签。
- **三态打卡（v2.3 新增）**：每天三种状态——✅ 完成 / ⏭️ 休息（Skip）/ 未打；休息日不清连续、不计未完成（完成率的期望天数中剔除）；每周弹性习惯的休息不影响本周目标。
- **打卡备注（v2.3 新增）**：打卡时可附一句话随想，长期回看打卡轨迹更有温度。
- **提醒（v2.3 修订，真正跑起来）**：应用启动时检查一次 + 运行中按分钟轮询；到达习惯的 `reminderTime` 且今日需要打卡、未完成也未休息时，发送本地通知（桌面端为系统通知/托盘联动）；每个习惯每周期最多提醒一次。
- **习惯详情统计（v2.3 新增）**：当月月历视图（完成/休息/未打三态）+ 近 12 周滚动完成率曲线 + 里程碑徽章（连续 7 / 21 / 66 / 100 天点亮）。
- **补打卡**：每个习惯可配置「允许补最近 N 天」，默认不允许，防止刷数据。
- **补签卡（v2.4 新增，streak freeze 温和版）**：每月 1 日自动发放 2 张，当月未用完不累积（鼓励当月使用）；用于补打「超出允许补打天数」的漏卡调度日，使用时扣 1 张，取消补签不返还；余额在习惯页展示，不足时提示下月再来。
- **emoji 图标选择器（v2.4 新增）**：习惯/表单的图标字段提供常用 emoji 网格一键选择，同时保留手动输入。
- **日历热力图**：近一年每天完成情况（多次打卡按天聚合、颜色深浅分档）、月份标签、今天标记、休息日独立配色；点击日期可打卡/取消/补打。（v2.3 已落地）
- **统计**：当前连续（按上语义）、最长连续（同语义）、总完成次数、最近 30 天完成率（期望次数按频率精确计算：daily = 30×N，weekly = 30/7×N，custom = 近 30 天内调度日数）。
- **时区约定（v2.2 新增）**：所有「今天」「日期归属」一律按用户本地时区计算，禁止以 UTC 截断（修复东八区 0–8 点日期归属前一天的问题）。

| 字段 | 说明 |
|------|------|
| 名称 | 如「早起」「背单词」 |
| 图标 / 颜色 | emoji + 主题色，列表里醒目 |
| 目标频率 | daily：每天 N 次 / weekly：每周 N 次（弹性）/ custom：指定星期几（weekdays，1–7） |
| 提醒时间 | 可选，本地通知 |
| 允许补打卡天数 | 默认 0 |
| 状态 | 进行中 / 已归档 |

#### 2.1.2 日/周/月/年四级计划
- **自上而下拆解，自下而上汇总**：
  - 年目标（大方向）→ 月计划 → 周计划 → 日计划（今天要做的具体事）。
- 每级计划支持：标题、描述、优先级、进度（0–100% 或勾选式子项）、状态（待开始/进行中/已完成/已取消）、关联上级。
- **父计划进度自动汇总（v2.5 新增）**：
  - 只有**叶子计划**（没有子计划）可手动填写进度；父计划进度 = 未取消直接子计划进度的平均值（四舍五入取整），状态随之派生：100% → 已完成，>0 → 进行中，0% → 待开始。
  - 子计划创建/更新/删除时，祖先链逐级向上自动重算；已取消的计划**不参与**汇总，也不会被自动改状态（取消是用户的显式意图）。
  - 勾选父计划 = 级联完成全部未取消的后代计划；取消勾选 = 已完成的后代恢复为待开始（进行中的后代进度保持不变，父计划会落在「进行中」）。
  - 编辑表单中，父计划的进度/状态字段禁用，并提示「由 N 个子计划自动汇总」。
- **树形计划视图（v2.6 新增）**：
  - 计划列表按层级缩进渲染为树：当前周期筛选出的计划为根节点，其子计划（可跨层级/跨周期，如年计划下挂月计划）逐级缩进挂载，点击箭头折叠/展开，默认全部展开。
  - 父节点显示子计划数徽标；勾选、进度、状态联动沿用自动汇总规则（勾父级联全部后代）。
  - 上移/下移仅在**同级兄弟**（同 parentId）之间交换顺序，不再跨父级移动。
- **删除级联（v2.7 新增）**：删除计划时递归删除其**全部后代**（子、孙……不再只删直接下级，杜绝孤儿节点）；删除确认框中显示将连带删除的后代数量。
- **逾期聚合视图（v2.8 新增）**：
  - 层级切换中新增「逾期」智能视图：聚合**所有已过周期**且未完成/未取消的计划（不受当前周期筛选限制），按年/月/周/日分区、周期升序排列，选项上显示逾期总数徽标。
  - 逾期判定以本地时区「今天」为基准，按周期字符串比较（year=『YYYY』、month=『YYYY-MM』、week=『YYYY-Www』、day=『YYYY-MM-DD』，均为等宽格式可安全比较）。
  - 日计划提供一键「结转今日」；所有逾期计划均可勾选完成（联动自动汇总）或删除（级联）。
  - 该视图下不提供排序移动（周期语义无意义）。
- **结转修复与确认式（v2.9 修订）**：
  - **补齐多天漏结转**：不再只看「昨天」——一次结转**所有**已过周期（period < 今天）的未完成/未取消日计划，隔几天没打开也不会漏。
  - **静默滚动改为确认式**：打开日计划视图（今天）时若存在过期日计划，弹窗确认「有 N 项过去周期的日计划未完成，是否全部结转到今天？」；确认后一次性结转并提示；取消则不动，计划保留在「逾期」视图中可逐项处理。同一自然日最多询问一次。
  - 设置中的「自动结转」开关语义调整为：开启 = 进入日视图时弹窗询问；关闭 = 既不询问也不结转。
  - **主面板不再静默结转**，结转动作统一收口在计划页，避免绕过确认。
  - Repository 签名相应变更：`rollOverIncompleteDayPlans(from, to)` → `rollOverOverdueDayPlans(to)`（补齐语义）。
- **未来 7 天视图（v2.10 新增，参考 Things 3 Upcoming）**：
  - 层级切换新增「未来 7 天」智能视图：聚合**今天起 7 天内（含今天）**的所有日计划，按天分组、从早到晚排列，与「逾期」视图构成完整时间轴（过去在逾期，未来在这里）。
  - 组标题带相对标签（今天/明天/后天/N 天后）与该日计划数；每组提供「+」快速创建该日计划（表单自动预填层级与周期）。
  - 计划可勾选完成（联动自动汇总）、编辑、删除；不提供排序移动。
- **周复盘视图（v2.11 新增，参考 Sunsama/GTD Weekly Review）**：
  - 层级切换新增「复盘」智能视图：以**周**为单位回顾（可翻页查看过去/未来任意周），统计该周「相关计划」——日计划取周期落在本周一至周日、周计划取本周、月计划取本周所在月、年计划取本年（已取消不参与）。
  - **四层完成率**：年/月/周/日各显示 完成率 + 完成数/总数；日计划完成率附**环比上周**（±百分点）。
  - **优先级分布**：执行层（本周日计划+周计划）按高/中/低优先级分别显示完成率与 完成数/总数。
  - **逾期提示**：显示当前逾期总数（不随复盘周期变化），有逾期时提供「去处理」跳转逾期视图。
  - 统计全部由前端从全量 plans 计算，数据层零改动。
- **今日计划在主面板置顶**，勾选即完成，未完成日计划的滚动见「结转修复与确认式」。
- 周视图：本周计划一览 + 完成率；月视图：本月里程碑。

#### 2.1.3 纸质书阅读书架 📚

##### A. 定位与设计原则
- **专注纸质书体验**：优先服务实体纸质书阅读场景（未来再扩展电子书/听书）。
- **零负担录入（不强制封面）**：
  - 无需费力到处搜封面图；若未上传封面，系统自动生成**高质感 CSS 拟物精装书封**（模拟书脊阴影、装订线、烫金微标与自选/智能雅致主题色）。
  - 支持自选手拍封面或输入网络图片 URL。

##### B. 纸质书基础信息
| 字段 | 说明 | 必填 |
|------|------|------|
| 书名 | 纸质书全称 | 是 |
| 作者 | 著译者信息 | 否 |
| 总页数 | 纸质书末页页码（如 `384`） | 是 |
| 当前页码 | 当前读到的页码（如 `128`） | 默认 0 |
| 分类标签 | 如：认知心理、哲学社科、技术、商业、文学、历史等 | 否 |
| 阅读状态 | **想读 (queue)** · **在读 (reading)** · **已读 (finished)** · **搁置 (abandoned)** | 是 |
| 封面图 / 颜色 | 真实封面图片 URL 或预设精装封面色系（如：山岚青、黑曜岩、落栗褐、鼠尾草绿、深海绀蓝） | 否 |
| 评分 | 读完评分 1~5 星 | 读完填写 |
| 购入日期 / 开始日期 / 读完日期 | 时间节点标记 | 否 |

##### C. 翻书打卡与阅读日志（Reading Logs）
- **案头极简记录**：
  - 在读卡片点击「翻书记录」：仅需输入**当前读到第 `X` 页**。
  - 系统自动计算**本次阅读页数**（如：*今天从 85 页读到 120 页，阅读了 35 页*）、**剩余页数与完成度百分比**。
  - 可附带一行随想短评或金句。
- **历史翻书记录列表**：清晰查看每一天的翻阅轨迹与阅读时间线。

##### D. 读书笔记与纸质书摘（Excerpts & Notes）
- **页码关联书摘**：记录心动金句时标记出自「第 `P.xx` 页」，还原折角划线纸质体验。
- **读完复盘**：一句话短评 + 3 点核心洞察收获。

##### E. 阅读洞察与年度挑战
- **年度阅读挑战目标**：设定「2026 年读完 N 本纸质书」，实时呈现达成度环形图与预计达标率。
- **阅读数据统计**：累计翻阅总页数、在读本数、已读本数、分类偏好分布。

##### F. 跨板块联动能力
- **联动习惯**：可关联「每日阅读」习惯打卡。
- **联动计划**：月度/季度计划可挂载「读完某书」任务。
- **联动日常**：读完或记录金句一键发送为带书封标签的日常动态。
- **联动主面板**：案头在读书籍快速翻书入口与年度阅读目标进度。

### 2.2 记账板块 💰

#### 2.2.1 记账
- 每笔记录：金额、类型（支出/收入/还款）、分类、账户、日期、备注、标签。
- **快速记账**：主面板固定入口 + 常用分类快捷按钮，30 秒完成。
- 支持按分类、账户、标签、时间范围筛选。
- **还款（v2.12 新增）**：还花呗/信用卡等信用账户欠款——选择付款账户与信用账户、金额；**不计入收支统计**（支出在消费当日已计），仅变动两侧账户余额，避免虚增支出。

#### 2.2.2 分类管理
- 内置常用支出分类（餐饮/交通/购物/居住/娱乐/医疗/学习/人情/其他，**v2.12 新增早餐/午餐/晚餐餐次分类**）与收入分类（工资/理财/兼职/其他）。
- 支持自定义分类：emoji 图标 + 颜色 + 父子层级。

#### 2.2.3 账户管理
- 账户：现金 / 支付宝 / 微信 / 银行卡 / 其他，含初始余额；**v2.12 新增信用账户（花呗/信用卡，kind=credit）**，余额可为负并以「欠款」形式展示。
- 账户余额 = 初始余额 + 收入 − 支出（实时计算）；还款使付款账户余额减少、信用账户欠款等额减少。

#### 2.2.4 预算
- 月度总预算 + 可选分类预算；主面板与报表页展示预算进度条，超支变红预警。
- **餐费预算（v2.12 新增）**：设置中配置早餐/午餐/晚餐的**每日额度**（长期有效，非月度计划）；主面板与预算页展示「今日餐费」卡片——每餐显示今日已花 vs 每日额度，超支红色、未超绿色（未消费的餐显示全额可用）；并累计**本月节约/超支金额**（已过天数内每餐 额度×天数−实际花费，正数累计为节约、负数累计为超支）。餐费记账通过内置餐次分类自然绑定，无需额外选择餐次。

#### 2.2.5 报表
- 本月收支概览、近 12 月趋势折线、本月分类占比环形图、账户余额分布。

### 2.4 记录日常板块 📔

### 2.5 主面板 🏠

主面板 = 全部板块的「今日快照」，自上而下：

1. **今日概览卡**：日期/星期 + 今日计划完成度 + 今日打卡进度条 + **在读书籍进度与年度目标**。
2. **快捷操作**：记一笔 · 打一次卡 · **翻书记录** · 写一条日常。
3. **财务卡**：今日支出、本月支出、预算进度条。
4. **提醒卡**：即将到期订阅、保修到期、待办逾期。
5. **今日计划列表**：直接勾选完成。
6. **最近动态**：最近 3 条日常预览。

## 5. 验收标准（第一版 MVP 范围）

第一版（MVP）必须满足（**先在 Mock 数据下全量验收，通过后再接入数据库**）：

- [ ] 账号：邮箱注册/登录、鉴权、多端数据隔离（接入数据库阶段）。
- [ ] 三端：Windows 桌面 + 网页 + Android 手机可登录使用，同一账号数据一致。
- [ ] 打卡：习惯 CRUD、一键打卡/取消、连续天数、日历热力图。
- [ ] 计划：日/周/月/年四级创建与查看，今日计划勾选完成，主面板可见。
- [ ] **阅读**：纸质书 CRUD、自动生成拟物精装书封（不强制封面）、翻书页码打卡、进度条计算、书摘笔记、年度挑战进度统计。
- [ ] 记账：收入/支出登记、分类、账户、月度预算进度、分类占比图。
- [ ] 资产：实物资产与订阅登记，到期日提醒（30/7/3/1 天分档）。
- [ ] 日常：文字 + 图片的时间线记录（图片上传，支持关联书籍）。
- [ ] 主面板：今日计划、今日支出、即将到期订阅、在读纸质书核心快照。
- [ ] 数据：Mock 数据下全量功能可用；接入阶段换 PostgreSQL 持久化 + JSON 导出/导入 + 多端同步。
- [ ] 移动端可用（响应式布局 + 拍照记日常）。
